RemoteControl v2 - 使用说明
============================

本目录可以直接拷到任何 Windows 10 x64 及以上的机器（含虚拟机）运行。
不需要安装 Visual Studio，也不需要 VC++ 可再发行组件包。

被控端（要显示画面的那台）
--------------------------
  双击 run-server.bat
  或命令行：  rc_server.exe --port 9999 --token mysecret --verbose

  首次运行 Windows 防火墙会弹窗，必须勾选"允许访问"。
  若当时点了取消：Windows 安全中心 -> 防火墙和网络保护
  -> 允许应用通过防火墙 -> 找到 rc_server.exe 并勾选"专用"。

控制端（你自己操作的这台）
--------------------------
  双击 run-client.bat，按提示输入被控机的 IP
  或命令行：  rc_client.exe --host 192.168.1.10 --port 9999 --token mysecret

  客户端是窗口程序，没有控制台。出问题时看同目录下的 rc_client.log。

常用参数
--------
  --token <口令>    两边必须一致。不填则不校验（启动时会打印警告）
  --scale 2         降采样一半，像素量 1/4，弱网或高分屏下明显更流畅
  --codec mszip     换成更省带宽的压缩算法（代价是帧率下降）
  --max-fps 30      限制服务端出帧率
  完整列表：rc_server.exe --help

客户端默认不在画面上画远端光标（本机鼠标指针已经在正确位置，
再叠一个只会看到两个箭头，而且慢的那个会被当成"鼠标延迟"）。
想要的话加 --show-cursor。

排错
----
* 双击后窗口一闪就没了：从 PowerShell 里运行，才能看到错误信息。
* 提示缺少 VCRUNTIME140.dll：这是旧版本构建的产物，请用/MT 重新构建。
* 提示"Windows 已保护你的电脑"：右键 exe -> 属性 -> 勾选"解除锁定"，
  或执行  Unblock-File .\rc_server.exe
* 提示"无法定位程序输入点 Compress"：目标系统低于 Windows 8。
* 杀毒软件拦截或直接删除：抓屏 + 输入注入的行为特征和远控工具一致，
  加白名单即可。

注意
----
* 默认不加密，画面和按键都是明文。只在可信局域网内使用；
  公网请套 VPN / SSH 隧道。
* 仅用于本人设备之间的学习实验，请勿用于未经授权的机器。
